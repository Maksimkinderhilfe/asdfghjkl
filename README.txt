DJ BREEZE – Spotify Only Stable

Render:
Build: npm install
Start: npm start

Environment Variables:
ADMIN_PASSWORD=...
SPOTIFY_CLIENT_ID=...
SPOTIFY_CLIENT_SECRET=...
SPOTIFY_REDIRECT_URI=https://hev-eisdisco-ai.onrender.com/auth/spotify/callback
OAUTH_STATE_SECRET=...

Kein OPENAI_API_KEY und kein PORT erforderlich.

Spotify Web Playback benötigt Spotify Premium. Der Browser gibt Audio über den normalen PC-Audioausgang aus; dieser kann per Kabel an die Anlage angeschlossen werden.
